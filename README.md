# Dulane Gestão e Tecnologia

Landing page da Dulane Gestão e Tecnologia (Angular).

## Rodando localmente

Duas partes: o app Angular e a API local de e-mail.

```bash
npm install
npm start        # ng serve, em outro terminal:
npm run api      # API local em http://localhost:3557, sem precisar de login no Vercel
```

Acesse `http://localhost:4200`.

## Build de produção

```bash
npm run build
```
